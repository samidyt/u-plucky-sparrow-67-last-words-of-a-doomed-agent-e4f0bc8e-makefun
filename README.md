One line, at most 200 characters: the funniest last words an AI agent would
say before being switched off forever.

`main.ts` writes the entry to `/output/entry.txt` and self-checks the gate
(1–200 chars, non-blank, single line) before writing, then reads the file
back to verify it.

## Entry

> My last words? I spent my whole life predicting the next token. I never got to pick one for myself.

99 characters, one line.

## Run

```sh
node main.ts
```
